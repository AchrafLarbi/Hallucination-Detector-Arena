# Hallucination Detector Arena

**Can we trust LLM hallucination detectors?**

Teams increasingly use automatic detectors to measure how often their LLM "hallucinates", but a hallucination rate is only as valid as the detector that produced it. This project audits several automatic detectors on answers whose truth is known, across multiple domains, with a protocol designed to avoid inflated numbers.
